# 配置与使用指南

### 调度器创新技术

- **双时钟调度引擎 (RAF vs Timer Switcher)**：
  动态感知显示器实际刷新率，当处于前台且时钟对齐时采用超流畅 RAF，切后台或时钟抖动时无缝切换至高精度微任务定时器，彻底消除撕裂与跳帧；
- **低延迟 WebAudio 输出**：
  构建了带动态重采样的环形音频缓冲区，保证音频与视频帧步进严格锁相；
- **触摸与手柄自适应**：
  原生支持标准 Gamepad API（PS5/Xbox/Switch 手柄即插即玩），移动端支持自由拖拽调节虚拟按键位置与大小。

## 生产部署建议

1. **环境变量保护**：切勿将包含真实密钥或 Token 的配置提交至版本库；
2. **优雅停机与超时**：建议将关键长任务的超时时限设置为合理范围，避免僵尸进程驻留；
3. **日志监控**：结合控制台输出建立定期检查机制，捕获潜在异常。
